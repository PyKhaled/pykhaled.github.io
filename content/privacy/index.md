This website uses Google Analytics 4 to understand how visitors use the site and which content is useful.

Analytics may collect information such as pages viewed, approximate traffic source, device and browser information, and interactions with links to external services such as GitHub, Medium, and LinkedIn.

This site also records selected interaction events, including clicks to GitHub, Medium, LinkedIn, contact links, and supported file downloads. These events are used to understand which projects and articles are useful to visitors.

Links shared from external platforms may include campaign parameters such as `utm_source`, `utm_medium`, and `utm_campaign`. These parameters help attribute visits to sources such as a GitHub repository, Medium article, or LinkedIn post.

Google Analytics is provided by Google. For more information about how Google handles data, review Google's privacy and analytics documentation.

No analytics data collected by this site is intended to include passwords, authentication credentials, or other secrets.
